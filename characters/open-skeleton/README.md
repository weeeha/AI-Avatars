# Open Skeleton

Round ivory mechanical character with a neck-free silhouette, realistic gray-green eyes, articulated lids, exposed brass/silver structure, and a hinged jaw.

[Animation gallery](preview.html) · [Manifest](manifest.json) · [Nine emotion clips](emotions/README.md)

The nine emotions are happy, curious, surprised, confused, concerned, frustrated, playful, proud, and relieved. All 12 clips use a 512 × 512 black canvas. The gallery crops the display into a circle; the head has clearance for its motion.

## Edit the gallery

Edit `studies/open-skeleton.fragment.html` from the repository root, then run `npm run build` and `npm run check`. The committed preview HTML, CSS, and JavaScript are generated by the shared gallery builder.

## Rebuild from generated artwork

The ready-to-play files are committed. Rebuilding is optional and needs Python 3, Pillow, NumPy, and ffmpeg with libx264 support available on PATH.

From the repository root:

```sh
python3 characters/open-skeleton/assemble_loops.py
python3 characters/open-skeleton/emotions/assemble.py
```

These scripts extract existing generated artwork and encode it locally; they make no generation API calls. Activity timing is in `assemble_loops.py`; reaction timing is in `emotions/assemble.py`. Exact art prompts are in the corresponding `prompts.json` files.

## Integration contract

Paths in `manifest.json` are relative to this character directory. The `clips` list contains only playable assets. `plannedActivities` lists concepts without clips. Activities can loop; emotional reactions should normally play once and return to the current activity. Reactions must not imply a task succeeded or failed unless that outcome really occurred.

These are silent keyframe studies. Runtime event integration, speech synchronization, and exact hardware fit are pending. The media files passed motion and boundary checks before import; the imported gallery has file-level checks, but has not been rechecked in a browser because its policy check was unavailable.
